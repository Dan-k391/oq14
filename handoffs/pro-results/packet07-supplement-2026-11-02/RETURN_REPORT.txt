CONVENTIONS THAT APPLY THROUGHOUT

Space is Euclidean R^3; the source axis is basis 2. A vector's physical
amplitude is ALWAYS the Hermitian Euclidean amplitude

    |v|_2 := sqrt(Maxwell.energy v) = sqrt(sum_{j=0}^2 |v_j|^2).

For complex angular vectors this is the Euclidean/WithLp 2 norm. In Lean,
Maxwell.Vector is the function type Fin 3 -> C and its DEFAULT Pi norm is
the sup norm; that default is not silently used for rotation-invariant
physical peaks. Coordinate superlevels imply Euclidean superlevels because
|v_j| <= |v|_2. This explicit convention resolves that representation issue.
Norms of real spatial vectors are Euclidean. Scalar absolute values are the
ordinary real/complex norms. Reciprocal pairings beta, d_phys and N use
complex BILINEAR dot products. Energy and power use Hermitian conjugation.

The one-sided physical envelope is

    E_up(x) = max {|E^alpha(x)|_2 : x in closure(Omega_alpha)},

using every incident material-side continuous representative, including the
vacuum side. On a compact observation ball it is upper semicontinuous and
attains a finite maximum under Packet 05's smooth-interface hypotheses.

The source's normalized weak Maxwell equations are

    curl E = i k H,       curl H = -i k epsilon E,
    epsilon = 1 + chi.

For the same unit-power source witness and a fixed physical Z0>0, the
power-preserving unit conversion is

    E_phys = sqrt(Z0) E_src,       H_phys = H_src/sqrt(Z0).

With Z0=1 this is the identity. Its justification and all constants are in
Part C. Dividing only H by Z0 is a different amplitude convention and would
divide the source power by Z0; it is not used to assert physical unit power.

1.2 What the actual scalar coefficient is.

Use Euclidean coordinates x=(x_0,x_1,x_2), with source axis e_3=basis 2.
Let C_p denote the real physical susceptibility represented by
ConicalStaticVolume.coefficient p. The named source definitions give

    C_p(x)
      = (coefficient p).value (VectorFourier.coordinateMap x)
      = ConicalAnnularSource.dielectric p.cutoff d t x - 1.

The actual dielectric is

    dielectric chi d t x
      = if x in closedBall 0 chi.rOut
        then ConicalCapField.permittivity d t x else 1.

In particular it is NOT the product of the bump value with an angular
coefficient. The bump cuts off the comparison fields. Its rOut enters the
material definition as a radial truncation.

The remaining defining bodies are

    unit x = if x=0 then basis 2 else ||x||^(-1) x,
    permittivity d t x = CapSturmLiouville.coefficient d t ((unit x)_2),
    CapSturmLiouville.coefficient d t z
      = if |z|<=t then 1 else 1+d.

Consequently, for x!=0, the high value is selected exactly when
|x_2|>t||x||. At x=0 the chosen unit vector is basis 2, whose last component
is 1; since t<1, the value there is 1+d. Thus the original susceptibility
at the origin is d. At the conical interface |x_2|=t||x||, x!=0, it is zero.

Now let 0<=a<=p.cutoff.rOut. ConicalSeparatedSource.material is literally

    material(p,a).value xi
      = if ||coordinateMap.symm xi||<=a
        then (coefficient p).value xi else 0.

Unfolding these definitions and using coordinateMap.symm(coordinateMap x)=x
proves the everywhere identity

    material(p,a).value(coordinateMap x)
      = d * 1_{S_{a,t}}(x),                              (G1.1)

    S_{a,t} := { x : ||x||<=a and
                      (x=0 or |x_2|>t||x||) }.

Proof by cases: if ||x||>a both sides vanish. Otherwise ||x||<=a<=rOut,
so the outer dielectric branch is active. If x=0, its angular value is high
as just computed. If x!=0, ||x||>0 and
|((unit x)_2)|=|x_2|/||x||; dividing the inequality by this positive norm
gives the stated strict cone inequality. Subtracting 1 from the high or low
permittivity gives exactly d or 0. This proves every pointwise case.

The radial boundary ||x||=a is included when its angular value is high.
If a=0, (G1.1) is d times the singleton indicator at zero. The construction
below uses a>0.

1.3 The a.e. dictionary and all relevant null sets.

For a>0 let the usual open truncated double cone be

    D_{a,t}:={x : 0<||x||<a and |x_2|>t||x||}.

The symmetric difference S_{a,t} triangle D_{a,t} is contained in
{0} union {||x||=a}. Both sets have three-dimensional Lebesgue measure zero.
For the sphere, for example, bound it by annuli
a-h<||x||<a+h and let h decrease to zero, using the volume of a ball.
The singleton is a null set in positive Euclidean dimension. Therefore

    material(p,a).value(coordinateMap x)
      = d * 1_{D_{a,t}}(x)       for almost every x.        (G1.2)

If another statement includes the angular boundary, that change is also
null. To see this without relying on an informal surface picture, put
u=(x_0,x_1), z=x_2 and beta=t/sqrt(1-t^2)>0. Since 0<t<1,

    |x_2|=t||x||  iff  z=+beta||u|| or z=-beta||u||.

This is a union of two closed measurable graphs. For each fixed u, its
vertical fiber has at most two points, hence one-dimensional measure zero.
Tonelli applied to its nonnegative indicator proves that each graph and
their union have three-dimensional measure zero. Orthogonal maps,
translations and positive dilations preserve null sets. Finite unions of
all translated cone, cap-sphere and tip null sets remain null.

In particular the origin convention is accounted for, not silently removed
from an asserted pointwise identity. The existing rounded inclusion may
exclude the tip at every finite index and still converge to this exact
sharp material almost everywhere, since that discrepancy is at a singleton.

PART B — G2: EXACT COMPONENTS OF THE EXISTING ROUNDING
=================================================================

1. Exact definitions and theorem

Fix a rounding index n, a slope m>0 and a truncation radius a>0. Write

  e = ConicalTipRounding.radius n = 1/(n+1) > 0,
  B(s) = ConicalTipRounding.scalarBump n s,
  c(u) = sqrt(m^2 ||u||^2 + e^2 B(||u||^2)),       u in R^2,
  s(u,z) = |z|-c(u),
  t(u,z) = a^2-||u||^2-z^2,
  C(s,t) = e^2 Theta(1-(s^2+t^2)/e^2),
  D(s,t) = 2st-C(s,t),
  Omega = {(u,z): s(u,z)>0, t(u,z)>0, D(s(u,z),t(u,z))>0},

where Theta is the actual Real.smoothTransition. Thus Omega is exactly
ConicalSmoothJunction.inclusion n m a. The physical set is its pullback by
ConicalJunctionPhysical.split x=(horizontal x,x_2), a linear coordinate
homeomorphism from Euclidean R^3 to R^2 x R. Its norm identity is

  ||x||^2 = ||horizontal x||^2+x_2^2.

Define Omega^+ = Omega intersect {z>0} and Omega^- = Omega intersect {z<0}.
The sole smallness hypothesis needed is the source's existing condition

  (S)       [4+(2m+2)^2] e^2 + e < a^2.

THEOREM. Under (S), Omega^+ and Omega^- are precisely the two connected
components of Omega. Each is a nonempty, open, bounded, path connected set
with C-infinity boundary. Their closures are disjoint and, quantitatively,

  dist(p,q) >= 2e min(1,m)

whenever p is in the physical closure of Omega^+ and q is in the physical
closure of Omega^-. The same theorem therefore holds for exactly the
existing ConicalJunctionPhysical.inclusion n m a.

For every fixed m>0 and a>0, (S) holds for all sufficiently large n, so the
theorem has quantifier order

  for every m>0 and a>0, there exists n0, for every n>=n0, the above conclusions.

Nonemptiness is asserted on this tail, not for every rounding index.
The lower bound on the gap is allowed to depend on n. It tends to zero as
n tends to infinity; no uniform positive separation in n is claimed.

2. Elementary estimates for the actual cap and correction

The ContDiffBump record has inner radius e^2 and outer radius 4e^2. Therefore
0<=B<=1, B(r^2)=1 for 0<=r<=e, and B(r^2)=0 for r>=2e. The cited source
already proves c is C-infinity, c(0)=e, and

  mr <= c(u) <= mr+e,                 r=||u||,
  c(u)=mr whenever r>=2e.

For the upper estimate, the radicand is at most m^2r^2+e^2, which is at most
(mr+e)^2; both sides of the final square-root comparison are nonnegative.

A further uniform-in-u positive lower bound is

  (L)       c(u) >= delta := e min(1,m) > 0.

Indeed, if r<=e, then B(r^2)=1 and c(u)>=e>=delta. If r>=e, the inward
estimate gives c(u)>=mr>=me>=delta. These cases include their common
endpoint and cover every u. This bound uses the bump's inner disk; mere
pointwise positivity of the radicand would not supply quantitative closure
separation without a compactness argument.

The supplied source proves Theta is C-infinity and nondecreasing, with
0<=Theta<=1, Theta(q)=0 iff q<=0, and Theta(1)=1. Consequently

  C(s,t)>=0,
  C(s,t)=0 whenever s^2+t^2>=e^2.

There is also the following order property on the nonnegative quadrant:

  if 0<=s<=s' and 0<=t<=t', then D(s,t)<=D(s',t').             (M)

To prove it, squares are ordered, so

  1-(s'^2+t'^2)/e^2 <= 1-(s^2+t^2)/e^2.

Monotonicity of Theta and e^2>0 imply C(s',t')<=C(s,t). Nonnegativity of the
four factors gives 2s't'>=2st. Subtracting gives (M). In particular, enlarging
both positive margins preserves strict positivity of D. This argument is
fully algebraic once transition_monotone is available; no assumption on
derivatives of c in the annulus e<r<2e is used.

3. A disk inside the positive lobe

Set

  z_* = (2m+2)e.

Since m,e>0, z_*>0. For every u with r=||u||<=2e, cap_upper gives

  c(u) <= mr+e <= (2m+1)e = z_*-e.

For every 0<=z<=z_*, (S) gives

  t(u,z) = a^2-r^2-z^2
         >= a^2-4e^2-z_*^2
         > e.                                                     (B)

At z=z_*, the cone margin is at least e and the ball margin is greater than
e. Thus C=0 and D=2st>0. We have proved the exact inclusion

  { (u,z_*): ||u||<=2e } subset Omega^+ .                          (Disk)

In particular b=(0,z_*) belongs to Omega^+, so this lobe is nonempty.
Reflecting b proves the negative lobe is nonempty. The closed disk is
contained in the open material because all three defining inequalities are
strict; s>=e is itself a strict positive lower bound.

4. Paths from every positive-lobe point to the disk

Take any p=(u,z) in Omega^+ and put r=||u||. Since z>0, the cone margin is
s=z-c(u)>0. We construct a finite concatenation of explicit continuous paths
from p to b, all lying in the same Omega^+.

Step A: shrink only the portion outside the cap-transition disk.

If r<=2e, no first path is necessary. If r>2e, let

  alpha(tau) = (1-tau)+tau(2e/r),
  gamma_1(tau) = (alpha(tau)u,z),                  0<=tau<=1.

The radius r_tau=alpha(tau)r ranges from r down to 2e and is always at least
2e. Thus cap_matches applies at every point of this path:

  c(alpha(tau)u)=m r_tau.

Both margins increase as the radius decreases:

  s_tau=z-m r_tau >= z-mr=s>0,
  t_tau=a^2-r_tau^2-z^2 >= a^2-r^2-z^2=t>0.

By (M), D(s_tau,t_tau)>=D(s,t)>0. The height remains positive. Therefore the
entire path lies in Omega^+, ending at transverse radius 2e. In the endpoint
case r=2e the constant path gives the same conclusion. No radial contraction
is asserted inside r<2e at an arbitrary height.

Step B: move vertically to the bridge height after reaching r<=2e.

Write the endpoint of Step A, or the original point if no Step A was needed,
as (v,z), with ||v||<=2e. Let

  z_tau=(1-tau)z+tau z_*,
  gamma_2(tau)=(v,z_tau).

There are two cases.

If z<=z_*, then z<=z_tau<=z_*. The cone margin satisfies

  s_tau=z_tau-c(v)>=z-c(v)>0,

and (B) yields t_tau>e. Hence s_tau^2+t_tau^2>e^2, C=0 and D=2s_tau t_tau>0.

If z>=z_*, then z>=z_tau>=z_*. The cap bound used for (Disk) gives

  s_tau=z_tau-c(v)>=z_*-c(v)>=e>0,

while the descending height gives

  t_tau=a^2-||v||^2-z_tau^2>=a^2-||v||^2-z^2=t>0.

Again s_tau^2+t_tau^2>=e^2, C=0 and D>0. In both cases every z_tau>0.
Thus gamma_2 lies wholly in Omega^+ and ends at (v,z_*).

Step C: contract inside the bridge disk.

Use gamma_3(tau)=((1-tau)v,z_*). Its transverse norm is at most 2e, so (Disk)
puts the full path in Omega^+. Its endpoint is b=(0,z_*).

The paths are continuous and their endpoints agree, so standard finite
concatenation gives a path from any p in Omega^+ to b. Reversing and
concatenating such paths joins any two points of Omega^+. Therefore Omega^+
is path connected. This is stronger than the connectedness required for G2.

5. The negative lobe, closure separation and exact component count

The reflection R(u,z)=(u,-z) is a homeomorphism and preserves c, |z|, z^2,
the two margins and the correction. It maps Omega^+ onto Omega^-. Hence the
negative lobe is also nonempty and path connected.

By (L), every point of Omega^+ satisfies z>delta and every point of Omega^-
satisfies z<-delta. Continuity of the height coordinate gives

  closure(Omega^+) subset {z>=delta},
  closure(Omega^-) subset {z<=-delta}.

The Euclidean distance between any points of these closures is at least the
absolute difference of their height coordinates, hence at least 2delta>0.
This yields the quantitative physical separation asserted in the theorem.

The inclusion condition s>0 implies |z|>c(u)>=delta>0. Therefore

  Omega = Omega^+ disjoint-union Omega^-.

Each half is relatively open in Omega, and its complement is the other
relatively open half, so each is also relatively closed. A connected subset
of Omega cannot meet both halves: its height image would be a connected
subset of R containing both a negative and a positive number, hence would
contain zero. But Omega contains no point of height zero. Thus every
connected component lies in one half. Since each half is nonempty and
connected, each is maximal connected and is one connected component. There
are exactly two; neither smoothness alone nor a lobe picture is being used
to infer this fact.

Both halves are open, because Omega is open and the height half-spaces are
open. The inequality t>0 puts the physical Omega inside the open ball of
radius a. Thus both halves are bounded, and their closures are compact in
finite-dimensional Euclidean space. All the path and closure assertions
transport through the physical coordinate homeomorphism without changing
the set or the material value.

6. Smooth boundary on the same smallness tail

The quoted CommonBinaryInterface.body_frontier_certificate and
eventually_body_smooth already furnish local regular C-infinity defining
functions for exactly the same source set under (S). The following direct
argument explains why our component proof introduces no new geometric
smallness requirement and also makes the mathematical smoothness claim
self-contained.

Let F(u,z)=D(s(u,z),t(u,z)). At a frontier point q of Omega, continuity and
limits from Omega give s(q)>=0, t(q)>=0 and F(q)>=0. Moreover q is not an
interior point. If F(q)>0, then 2s(q)t(q)>C>=0 forces s(q),t(q)>0, and all
three strict inequalities hold in a neighborhood, a contradiction. Hence
F(q)=0. The case s(q)=t(q)=0 is impossible because F(q)=-e^2 Theta(1)=-e^2.

The closure bound (L) gives |z(q)|>=delta, so the absolute value in s is
smooth on a neighborhood of q. The cap and correction are C-infinity, hence
so is F there. Put eta=Theta'(1-(s^2+t^2)/e^2)>=0. Direct differentiation of
the actual correction gives

  F_s=2t+2s eta,       F_t=2s+2t eta.

Case 1: s(q)=0 and t(q)>0. The equation F(q)=0 implies C(0,t)=0, hence
t>=e by Theta's zero characterization. Theta is identically zero on the
negative half-line and smooth at zero, so eta=0 for its argument <=0.
Consequently dF=2t ds at q. The z derivative of s is sign(z), which is

Insert the original equations C(E,f_q)=i*kappa*P(H,f_q) and
