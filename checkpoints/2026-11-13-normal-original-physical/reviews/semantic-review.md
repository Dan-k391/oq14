All eight exact source and author-log hashes match packet05-normal-original-physical-author-manifest.json. The modules were freshly rebuilt in listed dependency order with this retained object directory first in LEAN_PATH and the previously reviewed quantitative object directory second. All eight public reports use only propext, Classical.choice and Quot.sound; there are no warnings, placeholders, missing theorem reports, or custom axioms. Paths, commands, timings and final source/object/log hashes are in independent-build.json.

RoundedModeSupport derives support of the actual rounded coefficient from the fixed geometry; RoundedModeActualPhases combines that with the eventual regular-boundary theorem for each actual nonzero-frequency kernel mode.

DifferentiatedFluxNorm bounds the explicit differentiated forcing by the supplied metric and C/Fi norms. NormalFluxDataBounds and FirstNormalFluxDataBound bound the previously defined first and second conserved-flux arrays by the original C, F and first/second tangential derivative norms and explicit metric/cutoff bounds. NormalFluxOriginalBound inserts these estimates into the continuous normal-flux representative and preserves all weak-derivative, divergence, smoothness, and cutoff hypotheses.

PhysicalReconstructionBound derives the stated component bound using the inverse phase value, graph slopes and six input quantities. QuantitativePhaseBranches constructs globally continuous physical component representatives that agree AE on the stated phase region and satisfy the pointwise bound there, provided the stated continuous transmission representatives, flux identities, correction values, slope and input bounds.

These modules do not establish that the scalar derivative arrays and graph constants are uniformly controlled by the actual rounded-mode family, nor do they perform the remaining physical chart transport and finite-collar composition. No uniform collar bound is claimed.
