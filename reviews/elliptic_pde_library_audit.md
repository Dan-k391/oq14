# EllipticPDE library audit at the paper pin

Audit date: 2026-10-18. Scope: independent source and public build-evidence audit of the paper-pinned library, with a local compatibility probe against OQ14's existing compiler. **This is not an independent rebuild of the entire external library on its intended compiler. No OQ14 dependency pins or frozen Lean sources were changed.**

## Finding

The library contains substantial, genuine scalar elliptic PDE formalization: distributional Sobolev spaces, Poincaré, coercive variational solvability, proved Rellich compactness, Sobolev/Hölder embeddings, and quantitative interior regularity. Its scalar derivative predicates are actual integral identities; its headline compactness and regularity results are proved, rather than fields of a structure that assume those conclusions. It is a useful source of proof architecture and potentially reusable code.

It does **not** close the outstanding Maxwell formalization. It treats real scalar divergence-form elliptic equations. The missing Maxwell bridges include curl/div regularity, tangential traces and transmission, outgoing resolvents, unique continuation/Runge, and complex resonance analysis. In particular, scalar Rellich cannot be applied to an arbitrary bounded sequence in H(curl), and scalar C¹-coefficient estimates do not apply across a discontinuous dielectric interface.

Two qualifications matter for reuse. First, the more general bundled-coefficient interior route explicitly consumes `IsLipCoeff`, defined in `Regularity/CoeffLip.lean`, line 52, as a global Lipschitz bound for the chosen coefficient representatives. The source explicitly does not prove that an abstract W¹,∞ coefficient predicate automatically supplies such representatives. Do not erase that premise while porting a theorem. Second, boundary regularity has useful half-ball geometry, tangential difference quotients, and quotient-rule foundations, but the pinned [root module](https://github.com/alejandro-soto-franco/EllipticPDE/blob/da8dd98903148c0d61b36fb65277c3bfc5edd298/lean/EllipticPdes.lean#L194) explicitly leaves the headline boundary H² estimate open. No general boundary H² theorem was found in those files.

## Compatibility with OQ14

OQ14 currently uses Lean 4.19.0 and its existing pinned mathlib. I ran that exact compiler, under OQ14's existing `lake env`, on the unmodified external `Sobolev/Basic.lean`. The probe failed with exit code 1. Its source requires newer names and interfaces, including `PiLp.single`, `PiLp.single_eq_same`, `tsupport_fderiv_apply_subset`, `WithLp.toLp`, `PiLp.toLp_apply`, `Real.inner_apply`, and a different integration-by-parts derivative interface. There were also elaboration/time-budget failures. Thus this pin is **not a drop-in dependency** for the current project.

The captured probe is `tmp/external-audit/compatibility-4.19.txt`, with command, time, and exit code in `compatibility-4.19.json`. Any “declaration uses sorry” warning in this failed compatibility run is Lean's error recovery after unresolved constants, not a source admission and not a failed build on the library's intended compiler. No foreign `.olean` files were mixed into OQ14's environment.

A full migration could be considered separately, but it would require an isolated 4.31.0-rc1 toolchain, that exact mathlib lock, a clean external build, then recompilation and re-auditing of every OQ14 export. This audit does not recommend silently changing the working toolchain. Narrow source ports with attribution and new kernel checks are the smaller immediate experiment.

## Concrete next modules and remaining proof obligations

1. **Domain weak calculus.** OQ14's new `HCurlDomain.lean`, being implemented independently by the coordinator during this audit, supplies the first needed local-domain graph foundation. Next prove restriction, cutoff multiplication, and weak divergence on the same restricted L² representation. This should retain the current complex fields and actual distributional integrals. Relate compact C¹ tests to the external compact smooth test convention when transferring a result.
2. **Scalar gradient graph and complexification.** Port the minimum `W12` graph, compact-test derivative, and real/imaginary decomposition facts. Relate its Hilbert sum norm to the present finite-product graph norm by proved equivalences. Do not replace curl data by a full gradient without a theorem. The external basic module is a useful design reference, but the failed compatibility probe shows the amount of API adaptation required even at this first layer.
3. **Poincaré and scalar Poisson lifting.** Port a focused bounded-domain or ball Poincaré result and construct the scalar coercive variational solve. Our mathlib already provides the abstract coercive-form machinery used by the external Lax–Milgram proof; the genuinely useful additional work is its domain/weak-derivative bridge and Poincaré proof. Connect any resulting potential to Maxwell by proved distributional differential identities.
4. **Curl/div regularity or a regularized Poincaré lifting.** Prove the missing conversion from actual Maxwell fields to an H¹-controlled scalar/vector object, with domain and boundary assumptions visible. Only then use scalar Rellich, coordinate by coordinate. H(curl) alone does not compactly embed into L² on a bounded domain: bounded oscillatory gradient fields already obstruct that inference. Divergence control and appropriate geometry/boundary conditions cannot be omitted.
5. **Local scalar elliptic regularity and pointwise representatives.** Once a genuine scalar component equation and coefficient hypotheses are derived, the interior H²/higher-order/embedding development can accelerate the homogeneous-region regularity needed for collars and fields away from interfaces. For fixed real coefficients, componentwise real/imaginary transfer is feasible. Complex-frequency systems or coupled lower-order terms require additional proofs; they are not automatically covered by the real scalar statement.
6. **Transmission and Maxwell spectral analysis remain new work.** Piecewise constant ε jumps violate C¹/Lipschitz coefficient premises across the interface. Smooth rounded geometries do not by themselves give rounding-uniform constants; geometry-dependent bounds must be proved. Tangential traces, transmission matching, electromagnetic unique continuation, Runge approximation, radiation conditions, complex analytic Fredholm families, pole multiplicity and residue normalization remain outside this library's inspected results. Scalar real Dirichlet Fredholm and Laplacian spectral results cannot certify those claims.

The external library can reduce the amount of scalar analysis that must be developed from scratch. It does not change the current status: the complete continuum Maxwell and OQ14 conclusions are **not yet formally verified**.
