## 1. What the obligation is, precisely

Manuscript statement (`rg:remote`, in `radial_green_limit.tex`): fix a finite-band incident family with bounded physical coefficients, a gain A and a compact source ball. For the sum of the incident/background scattering field and the layered-shell source response, the absolute normal flux through the plane z = 0 is O(d_A/R^2) over the stack annulus and O(1/R) over the exterior, where R is the common starting radius of the stack and d_A its fixed thickness. Mechanism: states are bounded by the actual endpoint states throughout the barrier stack and the exterior (monotone `Re(p conj(u)) <= 0`, Wronskian cancellation, factorial tails), which gives tangential fields O(1/r) and radial fields O(1/r^2); the leading transverse far-field cross product has zero normal component on z = 0, so the remaining products are O(r^-3), integrable on the plane.

So, in the paired-shell reduction: flux = the absolute (not signed) normal Poynting flux density `|Re (E x conj H)_z|`, where E, H are the total fields (incident + material response) of the combined paired shell plus core inclusion, integrated over the part of the plane z = 0 outside the core, namely the stack annulus r in [R_n, X_n] and the exterior r >= X_n (here R_n = `(data q hq n r).R` -> infinity, the stack width fixed). Limit: shell index r -> infinity (radius -> infinity), for fixed gain/finite-band input and fixed source ball (inclusion carrier in `closedBall 0 b`). Uniformity: over unit coherent coefficient vectors of the finite family and over polarizations of bounded L2 norm in the source ball; constants may depend on gain and source ball but not on the (large) radius. Scale order: choose a, then remote radius -> infinity, then a diagonal a -> 0 (`uc:counterexample`). It is the third summand missing from the explicit-kernel whole-plane flux `ParityCompleteLimit.total_to_trial`, which only compares the explicit-kernel total with the explicit static trial (core region), and from `FiniteSpherePlaneLimit.actual_inverse_limit`.

## 2. What is proved in Lean about whole-plane flux

Whole-plane flux of the explicit parity kernel (no shell): `OQ14.ParityCompleteLimit.total_to_trial` (hypotheses: `hR : 0 <= R`, `hk : k != 0`, `hT : 2 <= T`, `hTR : 2R <= T`, `hgamma`, `hC`, `hM`, `hA0`, admissible sources `rho a`, `sigma a` of height gamma*a, source masses <= M a^2, mass of difference <= C a^3, coefficient mass `sum ||A a s|| <= A0/a`; conclusion) `Tendsto (fun a => integral q : Plane, ||ParityTotalFlux.totalFlux k (b/a) (rho a) (p a) (j a) (A a) q - ParityTotalFlux.freeFlux k (sigma a) (p a) (j a) (A a) q||) (nhdsWithin 0 (Ioi 0)) (nhds 0)`. Its concrete instance for finite spheres is `OQ14.FiniteSpherePlaneLimit.actual_inverse_limit` (same conclusion, `let S := FiniteSphereActualSources.source ...`, `U := ...trial ...`). These bound the whole plane, but for the kernel with parameter `b/a` and sources inside the core, with no shell.

Shell side, all of the following are proved but none is a plane-flux statement. (i) Fixed-degree radial limits: `RadialFiniteLimit.physical_pairs_limit` (limit of the propagated state of the pair stack as R -> infinity), `RadialPhaseLimit.normalizedCoefficients_limit`, `RadialPhaseLimit.actual_gamma_limit : Tendsto (fun n => RadialSource.gamma l (layers gs (radius n) _) (radius n) (radius n + width gs) _) atTop (nhds ((limitingCoefficients l gs).1 / (limitingCoefficients l gs).2))`. (ii) Fixed-degree far amplitude of the actual layered source: `SourceFarAmplitude.electric_ray_limit : Tendsto (fun r => electricWeighted d P (r • n)) atTop (nhds ((amplitude d * phase d.l * I) • HarmonicRadiationFactors.poloidal P n))`, `magnetic_ray_limit` (limit `(-I*amplitude d*phase d.l) • DebyeRadialTrace.angularToroidal P n`), and the exact exterior formulas `electric_exterior`, `magnetic_exterior`, `electric_ray`, `magnetic_ray`; `SourceRadiation.radiationDefect_limit` and `SourceTERadiation.radiationDefect_limit` (pointwise defect tends to 0 along any sequence with norm -> infinity); `PointDyadicFarField.electric_limit` (translated point dyadic far amplitude). (iii) Local convergence of the paired shell Green tensor on compacta: `SourcePairedTensor.uniform_actual_jet_limit (q hq n m b hb i j eps heps) : ∀ᶠ r, ∀ p : Region b, ||iteratedFDeriv ℝ m (kernel q hq n r i j) p.val - iteratedFDeriv ℝ m (VectorLimitIdentification.kernel q n i j) p.val|| < eps`, and the operator-level reduction in `SourcePairedReduction`. (iv) Compact-annulus tails for the scalar reaction: `RadialEntireTail`, `RadialReactionTail`, `RadialHighOrderBound`, `RadialFullMajorant` (summable bounds for the reaction kernel and its first mixed derivatives on compact radius ranges). (v) Vacuum transverse cancellation: `TransversePlaneFlux.leading_zero` (leading far electric field cross conjugate tangential magnetic field has zero z-component on z = 0).

Not proved in Lean: any all-degree, uniform-in-R bound of the radial states of the shell response for r >= R (`rg:states`), any absolute plane-flux bound for the shell, annulus layers or exterior (`rg:remote`), and the link from the shell's remote field to the unit-coefficient-sphere uniformity. The CLAIMS rows `rg:physical-limit`, `cl:remainder`, `ct:completion` record these as proved at the manuscript level. The stage note `source_tensor_limit_stage_2026_10_23.md` states the same gap ("control the remote annulus's whole-plane return flux"). `channel_transducer_limit.md` and `nearby_transducer_audit.md` give the history: the remote flux was the originally open bridge, later discharged in the manuscript.

## 3. Missing Lean theorems, by size

(A) Single-mode exterior plane flux density (smallest). `∃ r0 C, 0 <= C ∧ ∀ x, x 2 = 0 → r0 <= ‖x‖ → d.X < ‖x‖ → ‖crossProduct (SourceUnclippedMaxwell.electric d P x) (conjugate (SourceUnclippedMaxwell.magnetic d P x)) 2‖ <= C/‖x‖^3`. Feasibility high (done, see section 4).
(A') The same for TE source modes (`SourceTERadiation`), and the integrated tail `Tendsto (fun R => ∫ q in {‖q‖ >= R}, ‖f q‖) atTop (𝓝 0)` from (A) with the plane tail integrability of r^-3 (`MaxwellPlaneTail`). Feasibility high to medium (hours).
(B) Finite-band sum: for a finite set of modes and coefficients, the sum of single-mode fields satisfies the O(r^-3) bound with a constant linear in the coefficients' norms. Feasibility high once (A), (A') are in place (bilinearity of the cross product; cross terms between modes need the same cancellation, which holds since orthogonality of the tangential factors is per pair, not per mode, and needs separate care: the tangential-tangential product between different modes l, l' is not covered by `poloidal_cross_zero`, which uses the same T for both fields. Honest caveat: this requires the pairing `(pol_l x T_l')_z`, which also vanishes since both are tangent, so the proof is analogous but not literally (A)).
(C) Uniform all-degree state bounds `|f_lm| (|u_l| + |p_l|) <= C ||P||_2 ...` summable in l uniformly for R >= R0 (the Lean content of `rg:states`: low/middle orders by the transfer bounds, barrier orders by monotone `Re(p conj(u)) <= 0`, Wronskian cancellation `w(R) = 1/(h psi - psi')`, exterior monotonicity of Hankel modulus and derivative modulus). Feasibility low: several days; reuses `RadialLowTail`, `RadialMiddleTail`, `RadialHighOrderTail`, `RadialStackHighTail`, `RiccatiBarrier`, `HankelPositive` but those are stated for the reaction kernel on compact ranges, not for the outgoing states for r in [R, infinity).
(D) Annulus layers: the same flux on the stack annulus with the layer equations (tangential continuity) and the barrier-stack monotonicity, giving O(d_A/R^2). Feasibility low: needs (C) plus a layerwise Maxwell field representation for the paired stack, and the fixed-thickness bookkeeping.
(E) The full obligation: (C) + (D) + uniform in coefficient sphere and in the source ball, plus linking the shell's remote field to the total field of the combined system (the combined solution formula is delivered in `SourcePairedSolutionFormula`, and the inclusion enters through the reaction operator). Feasibility low.

Ranking by feasibility: (A) > (A') > (B) > (C) > (D) > (E).

## 4. Attempt of the smallest one

Delivered (A): `lean/SourceRemotePlaneFlux.lean`, theorem `OQ14.SourceRemotePlaneFlux.plane_flux_bound`, with the constant `C = 8‖amplitude d‖² l(l+1) M1 M2`; see `reviews/source_remote_plane_flux.md` for hashes and logs. It is a single-mode result: the constants depend on the degree and polynomial, so it is not yet uniform over degrees and does not cover TE, the annulus or the inclusion. It does show that the mechanism "tangential product has zero normal component, only the radial electric component contributes and is O(r^-3)" holds in the actual Lean field representation, so (A') and (B) are reachable next without new analysis.
