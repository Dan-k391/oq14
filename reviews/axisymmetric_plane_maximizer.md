A function F on R^3 is axisymmetric about the third axis if F x = F y whenever x0^2 + x1^2 = y0^2 + y1^2 and x2 = y2 (stated this way instead of through rotation matrices, so no rotation group is needed). Given p with p1 = 0, the fold of x is the point (sigma sqrt(x0^2 + x1^2), 0, x2), where sigma is 1 if p0 is nonnegative and -1 otherwise. It lies in the plane x1 = 0, has the same value of F, and is no farther from p than x (reverse triangle inequality for the planar radii: x0 p0 is at most |x0| |p0|, at most sqrt(x0^2 + x1^2) |p0|). Hence a maximizer of F over any closed ball about p can be replaced by one in the plane x1 = 0 inside the same ball (`exists_maximizer_in_plane`), and for continuous F and nonnegative radius a maximizer in that plane exists (`exists_plane_maximizer`, by compactness).
