The module turns the state-magnitude decomposition of `BarrierDegreeFluxConstants.tm_decomp_state` into per-degree constants that do not depend on the shell index, for the modes normalized by the regular value `regular l s0` at a fixed inner scale `s0 > 0`, at every point strictly outside the inner radius `R` (annulus and exterior alike). Regimes, at every radius `r > R` and for a layered datum with layer parameters `1 <= sigma <= q^2`, `q_g <= q`, `X - R <= W`, `X <= 2R`: low degree `2(l+1) <= R` (`state_bound_low`): both squared state magnitudes are at most `Ulow (q^2) W`, which depends on neither `l`, `R` nor the shell index (frozen `low_annulus_state_bound` and `low_exterior_state_bound`); intermediate degree `l <= 2qR` (`state_bound_middle`): at most `midConst q (q^2) W * exp(6 e R)` with `e = HankelIntermediateBounds.exponent q`; barrier degree `2qR <= l`: the geometric source-weighted bound `source_weighted_all_high`. `weighted_state_bound` combines the three. Given a threshold `R1` with `max 1 (max W s0) <= R1 <= R`, it shows that `|regular l s0|` times either state magnitude is at most `Ub q W s0 R1 l = |regular l s0| * (sqrt (Ulow (q^2) W) + sqrt (midConst q (q^2) W) * exp(6e(l+1))) + exp(l/(4q)) (s0/R1)^(l+1)`. In the barrier case this uses `2R/(l+1) <= 1`, `exp(R/2) <= exp(l/(4q))` (from `R <= l/(2q)`) and `(s0/R)^(l+1) <= (s0/R1)^(l+1)`; in the intermediate case the regime `l > R/2 - 1` (not low) turns `exp(6eR)` into `exp(12e(l+1))`, and the factor `|regular l s0|` is kept because it decays factorially. `mode_decomp_uniform` then gives, for the real mode `m`, `Decomp (Kone) (Ktwo)` for `regular l s0 * electric` and `Decomp (Lone) 0` for `regular l s0 * magnetic`, with `Kone = (l+1) envelope(l) Ub`, `Ktwo = l(l+1) envelope(l) Ub`, `Lone = 2 envelope(l) Ub`, all independent of `R` once `R >= R1`.

Summability (`summable_Ub_weighted` and its corollaries): if `base * exp(1/(4q)) * s0 < R1` then `(l+1)^j envelope(l) Ub` is summable for every `j`. The inner-scale regular value satisfies `|regular l s0| <= s0^(l+1)/l!` for `l >= s0` (`regular_abs_le`, from the actual upper bound of `RiccatiGaussianBound` and `amplitude <= 1/l!`), so the weighted part is dominated by a constant times `(2^(j+3) base s0 exp(6e))^l / l!` (exponential series) and the barrier part by a constant times `(l+1)^(j+3) rho^(l+1)` with `rho = base exp(1/(4q)) s0 / R1 < 1`; the finitely many degrees below `s0` are absorbed through `Summable.of_norm_bounded_eventually_nat`. The constants depend on `q`, on `s0` and, through the width `Wpair`, on `n`; they are not uniform in `n` and are not claimed to be sharp.
