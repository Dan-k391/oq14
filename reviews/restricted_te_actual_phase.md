Why. The modal computation gives, for the paired TE stacks, `input (scaledCoeff A (transInf q hq n)) = (q^n * parityPhase q n) • input A` for every `A` (a global unimodular constant `parityPhase q n`, independent of the degree), while the vector identity `scaledCoeff A transInf = q^n • (twist A)` holds only for even-supported `A` (odd-degree and degree-zero entries are rescaled by `q^(-n)` but have zero physical input). So the fixed unitary twist of `actual_counted_subspaces_of_core` / `_of_pieces` (`htw`) cannot be satisfied. This module replaces `htw` by the input-level identity and handles the phase by rephasing the fields.
