Proved: the explicit off-diagonal entries of the static kernel at k = 0, `phiHessian 0 z i j = 3 z_i z_j/(4 pi |z|^5)` for i != j (`phiHessian_static_off`), and the tangential-normal entries at a plane point seen from a dipole at height t above c: `phiHessian 0 (planePoint q - abovePoint c t) i 2 = -(prof t (q-c) * (q-c)_i)` with `prof t xi = 3t/(4 pi (|xi|^2+t^2)^(5/2))` (`hess_tangent_normal`). For a unit vector n of the plane, the tangential profile `psi n t xi = <n,xi> * prof t xi` is continuous, dominated by (3/(8 pi)) times the existing inverse-cube envelope (`abs_psi_le`) and integrable. The half-disk and half-plane integrals `halfDisk n t S`, `halfPlane n t` satisfy the exact scaling identity `a * halfDisk n (h a) s = halfDisk n h (s/a)` (via `Measure.integral_comp_smul` and the scaling law `prof (h a) (a eta) = (a^4)^-1 prof h eta`), `halfDisk n t S -> halfPlane n t` as S -> infinity (dominated convergence), and therefore `scaled_limit`: `a * halfDisk n (h a) (s a) -> halfPlane n h` as a -> 0+ whenever s a / a -> infinity. For a section D that coincides with the half plane {0 < <n,q-c>} in the disk of radius s about c, `model_pos` computes the local model passage as `halfDisk n t s` and `model_neg` computes the local absolute bypass outside D as the same number (reflection xi -> -xi, `neg_side`).

Not proved: the closed form of `halfPlane n h` (it equals 1/(2 pi h) by direct integration but this is not formalized and not used; only its finiteness, from the envelope bound, enters); positivity or rotation invariance of `halfPlane` in n.
